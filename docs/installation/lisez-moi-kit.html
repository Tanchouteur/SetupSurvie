Commencer avec le SSD SetupSurvie

Cette page se lit directement depuis le SSD, même avant d’installer SetupSurvie. Ouvrez le dossier app du SSD dans votre gestionnaire de fichiers pour retrouver les lanceurs cités ci-dessous.

Installer SetupSurvie

Sur Windows

  1. Vérifiez que le dossier installateurs-windows est présent à côté de app. Il doit avoir été préparé avant le départ si les composants Windows sont à installer.
  2. Dans app, double-cliquez sur Installer-SetupSurvie.cmd. Autorisez l’administration quand Windows le demande. Si Docker Desktop affiche sa licence ou ses réglages, suivez les indications à l’écran.
  3. Si le PC demande un redémarrage, laissez le SSD branché et rouvrez le même lanceur ensuite.
  4. Choisissez l’emplacement quand il vous est demandé. Attendez la fin, puis ouvrez SetupSurvie depuis le raccourci installé.

Le parcours demande Windows 11 24H2 ou ultérieur, un PC x64 et la virtualisation activée. Gardez les instructions Windows à portée de main si une étape s’arrête.

Sur Linux

Ce kit public s’installe sur un PC Linux déjà préparé avec Python 3.11 ou ultérieur avec Tkinter, Docker et Compose. Le moteur Docker doit être démarré et accessible depuis votre compte.

  1. Dans app, ouvrez Installer-Kit-SetupSurvie.desktop. Si votre gestionnaire de fichiers le demande, choisissez d’autoriser le lancement.
  2. Choisissez le disque. La fenêtre vous montre le nouveau dossier avant de lancer la copie. Le site s’ouvre à la fin, avec l’IA en pause.
  3. Après un redémarrage, ouvrez Ouvrir-SetupSurvie.desktop dans le dossier installé. Cette fois, vous pouvez laisser le SSD de secours débranché.

En cas de coupure pendant cette première installation, relancez depuis le kit vers un nouveau dossier. Pour les commandes de secours, ouvrez le guide du pilote.

Pour préparer automatiquement un PC Debian 12, Debian 13 ou Ubuntu 22.04 x86-64, il faut la copie de secours Linux complète. Sur cette copie, ouvrez Installer-SetupSurvie.desktop. Le lanceur demande où installer le site et propose de créer un point de restauration protégé.

Retrouver mes données

Préparez Python avec Tkinter, Docker et Compose sur l’ordinateur cible. Prenez aussi le dossier de sauvegarde personnelle qui contient backup.json et le kit public de la même version.

  1. Dans app, ouvrez Restaurer-Mes-Donnees-SetupSurvie.cmd sous Windows ou Restaurer-Mes-Donnees-SetupSurvie.desktop sous Linux.
  2. Choisissez le dossier de la sauvegarde, puis le disque de destination. Après une interruption, faites les mêmes choix et acceptez de reprendre.
  3. Ouvrez un ancien échange et un document personnel avant de retirer le SSD. Après un redémarrage, utilisez Ouvrir SetupSurvie dans le dossier restauré.

Gardez la sauvegarde d’origine sur un support distinct. Le kit fournit le logiciel et les ressources communes. La sauvegarde apporte les profils, conversations et documents personnels qu’elle contient.

Copier le kit sur un autre disque

Branchez le second disque. Dans app, ouvrez Dupliquer-Kit-SetupSurvie.cmd sous Windows ou Dupliquer-Kit-SetupSurvie.desktop sous Linux. Choisissez le dossier sur le second disque et attendez la confirmation avant d’éjecter les supports. Si la copie s’interrompt, rouvrez le même lanceur et choisissez le même dossier pour reprendre.

Résoudre un problème

  • Gardez le SSD et les données existantes. Notez le message affiché et l’étape qui s’est arrêtée.
  • Si le lanceur demande un composant absent, vérifiez les fichiers préparés pour le système cible. Consultez les instructions Windows ou Linux ci-dessus.
  • Le manuel de secours est sur ce SSD. Si votre navigateur ne l’affiche pas, ouvrez le fichier app/docs/exploitation/manuel-de-secours.md avec un éditeur de texte.
