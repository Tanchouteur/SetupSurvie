# Notice à la racine du kit public

**Bilan daté — 22 novembre 2026, SetupSurvie 0.98.0.** La version mineure
ajoute un point d’entrée lisible dans le navigateur avant installation et un
mode CPU pour installer le kit public sur un PC Linux déjà préparé.

La notice est inventoriée à l’export et lors du rafraîchissement du kit.
Le test duplique un kit réduit, compare la notice octet par octet et vérifie
qu’une modification est détectée. Le test d’installation portable couvre
l’enregistrement du mode CPU avec des services simulés. Chromium a ouvert
la notice depuis un fichier local dans un conteneur sans réseau.
Les étapes physiques
et la lecture du guide par une personne qui découvre le produit restent à
qualifier.
