## Règles pour les nouveaux bilans

Préciser machine, système, version, commandes, résultats et limites. Ne pas
transformer un essai Linux en validation Windows ni un test WebKit en essai réel
sur iPhone. Un ancien nombre de tests ou de ressources ne décrit pas
nécessairement la livraison suivante. Ajouter chaque nouveau bilan sous sa date
dans cet index. Pour installer le pilote actuel, suivre les
[guides de référence](../README.md).
