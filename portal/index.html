Comptes de l’appareil
Mot de passe oublié ?
La personne peut utiliser son code de secours depuis « Se connecter → Mot de passe oublié ». Vous pouvez aussi choisir un nouveau mot de passe dans la liste des comptes.
Les conversations sont conservées. Les anciennes sessions sont invalidées après le changement du mot de passe.
Rôles et gestion avancée
