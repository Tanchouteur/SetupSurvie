    Ajoute les adresses et lieux OpenStreetMap disponibles, et le relief si sélectionné. Les coordonnées de la zone sont transmises aux fournisseurs. Le fond de carte se prépare séparément ; toutes les adresses ne sont pas recensées.

    PROFILS DE LA FAMILLE
    Un espace pour chaque personne.
    Les profils rangent les conversations et les favoris. Ils sont accessibles à tous les utilisateurs du réseau local, sans mot de passe. Le profil Famille permet aussi d’ouvrir les réglages.
    Créer un profil
    Profils de l’appareil
    Changer de personne
    Utilisez le nom du profil affiché dans le menu pour en choisir un autre. Aucun code de secours ni mot de passe n’est nécessaire.
    Les anciens comptes deviennent des profils ; leurs conversations et favoris sont conservés. Un profil sert à organiser les échanges, pas à les cacher aux autres personnes du réseau.
