# Première piste d’identité

Concept : feu de camp et livre ouvert, pour la survie et la transmission des connaissances hors ligne.

Logo : `logo-feu-livre-v1.png`, première proposition bitmap générée avec l’outil intégré image_gen. Nom du produit encore à choisir. Intégré au portail (accueil, navigation, favicon et icône Apple) et au README du dépôt. Les variantes redimensionnées sont conservées dans `portal/branding/`.

## Noms proposés

- Braise : conserver le savoir pour le raviver ; piste préférée.
- Silex : outil essentiel, autonomie, étincelle.
- Feu de Savoir : lien explicite entre feu et connaissances.
- Le Refuge : protection et bibliothèque familiale.
- Veille : préparation, présence et lumière qui reste.

Pistes créatives ; disponibilité des noms non vérifiée.

## Prompt utilisé

```text
Use case: logo-brand
Asset type: first logo concept for a French offline knowledge library and local AI survival appliance, for families.
Primary request: Create one distinctive, professionally designed standalone symbol combining a campfire with an open book. A confident simple flame above two broad open book pages which also subtly read as crossed campfire logs. Convey survival, preserved knowledge, resourcefulness, warmth and transmission.
Style/medium: clean flat vector-like brand mark with crisp silhouette, balanced geometry and excellent small-icon legibility. Make it feel welcoming and durable.
Composition/framing: one centered logo symbol, generous clear space, square composition, transparent background. Strong unified shape, a few bold solid shapes, restrained colors suitable for the campfire subject. No complex scene.
Text: none.
Constraints: actual transparent background; no letters, brand name or typography, no watermark, no mockup, no photo, no gradients, no shadows, no thin intricate lines, no military imagery. This is a single usable logo concept, not a presentation board.
```
